# Challenge-Telecom-X

Informe Final 
📌 Introducción

Telecom X enfrenta una tasa alta de cancelación (churn). El análisis busca identificar factores que influyen en la evasión de clientes.

📌 Limpieza y Tratamiento

Se cargaron los datos desde un archivo JSON.

Se eliminaron duplicados y se trataron valores nulos.

Se estandarizaron variables binarias.

Se creó la columna Cuentas_Diarias.

📌 Análisis Exploratorio

La evasión representa aprox. X% de los clientes.

Contratos mensuales y pagos electrónicos concentran más bajas.

Clientes con baja permanencia (tenure bajo) presentan más evasión.

Cargos mensuales altos están relacionados con churn.

📌 Conclusiones

Contrato mensual + pago electrónico = mayor riesgo de churn.

Tenure corto es un fuerte predictor de evasión.

Cargos altos generan cancelaciones más frecuentes.

📌 Recomendaciones

Implementar promociones a clientes con contrato mensual.

Crear programas de fidelización para clientes nuevos (<1 año).

Ajustar planes con cargos altos.

Mejorar la experiencia de pago electrónico.
